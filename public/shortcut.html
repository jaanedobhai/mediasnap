iPhone & iPad

MediaSnap
iOS Shortcut

To get the perfect native iOS experience without 'Unknown Action' errors, you need to create the shortcut once on your iPhone, then we will use your iCloud link here for 1-click installs!

1
Create a new Shortcut on your iPhone

Open the Shortcuts app, tap +, name it MediaSnap, and change the icon to a Film Reel or Play button.

2
Enable Share Sheet

Tap the (i) info icon at the bottom, turn on Show in Share Sheet, and set it to receive URLs.

3
Add API Action 1 (Fetch Info)

Add a Get Contents of URL action and paste this URL (pass the Shortcut Input as the url parameter):

https://mediasnap-eyhq.onrender.com/api/info?url=[Shortcut Input]
4
Add Menus & Download

Add a Choose from Menu to pick Video/Audio, then use this download URL for the second Get Contents of URL action:

https://mediasnap-eyhq.onrender.com/api/download?url=[URL]&formatId=[Format]

Finally, add a Save File action.

5
Share the iCloud Link!

Once it works perfectly on your phone, tap Share → Copy iCloud Link. Send that link to me, and I'll add it to this website for a true 1-click install!
